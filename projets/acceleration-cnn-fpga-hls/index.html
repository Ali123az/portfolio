01Contexte

Projet en trinôme mené en dernière année à l’ENSEEIHT. Exploration du flot complet de conception pour l’accélération matérielle d’un CNN : de l’implémentation C++ jusqu’à la validation sur carte FPGA pilotée par le cœur ARM.

02Chaîne technique

  1. 1CNN C++ (toutes couches)
  2. 2SystemC testbench
  3. 3HLS Catapult (Unroll+Pipeline)
  4. 4RTL VHDL généré
  5. 5IP Vivado + AXI
  6. 6Validation Vitis ARM

03Ce que j’ai réalisé

  1. 01

    Implémentation C++ de toutes les couches CNN : Conv2D (zero-padding, multi-filtres, multi-channels), MaxPool (fenêtre glissante), Flatten, ReLU, Softmax. Réécriture avec buffers (copyCenteredWindow) pour réduire l’empreinte mémoire.

  2. 02

    Modélisation SystemC de Conv2D : SC_MODULE, ports sc_in/sc_out, processus conv2D.process(), compteur outFmapCpt, chargement poids/biais JSON. Temps mesuré ≈ 200 ms.

  3. 03

    Exploration contraintes HLS Catapult sur Adder : sans contrainte (80 ns) → Pipeline=2 (40 ns) → Pipeline=1 (20 ns, surface optimale 1048 vs 1462).

  4. 04

    Optimisation HLS Conv2D : sans contrainte (1178 µs/filtre) → 4 Unrolls (519 µs) → Pipelines=2 boucles internes (455 µs, ×2,6 vs baseline).

  5. 05

    Vivado : IP packaging Adder et Conv2D, block design avec FIFO AXI-Stream + AXI Interconnect + Zynq-7000, PLL 100 MHz, génération bitstream.

  6. 06

    Vitis : validation de l’additionneur sur Zybo (initialisation FIFO, remplissage, envoi, réception, comparaison — additions correctes, UART OK). Conv2D : IP intégrée au block design, validation sur carte restée partielle (adressage mémoire côté Vitis).

05Difficultés rencontrées

  • Optimisation HLS limitée par structure FIFO : boucles supérieures bloquées à Pipeline ≥ 10
  • Trade-off contre-intuitif : Pipeline=1 sur Adder est plus rapide ET plus compact (1048 vs 1462 sans contrainte)
  • Mémoire partagée statique sous Vitis : passage à une allocation dynamique ; la validation complète de Conv2D sur carte est restée ouverte
  • Flot hétérogène : VSCode, Catapult, Vivado, Vitis, formats .xsa / bitstream / IP core

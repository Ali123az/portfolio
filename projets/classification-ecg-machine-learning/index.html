01Contexte

Projet en binôme à l’ENSEEIHT : comparaison de méthodes supervisées et non supervisées sur des données biomédicales réelles (base MIT-BIH Arrhythmia).

02Chaîne technique

  1. 1MIT-BIH dataset
  2. 2ACP 23 composantes (90 %)
  3. 3GridSearchCV
  4. 4RandomForest 200 est.
  5. 5SHAP + Boruta

03Ce que j’ai réalisé

  1. 01

    DTW (Dynamic Time Warping) : calcul du signal médian par classe (6 min vs >30 min brute), baseline 0.575.

  2. 02

    KNN : GridSearch → metric Manhattan, k=1, accuracy 0.924.

  3. 03

    RandomForest : 200 estimateurs, GridSearch → accuracy 0,925 (meilleur résultat).

  4. 04

    KMeans : optimisation par analyse de silhouette → 39 clusters → accuracy 0.790.

  5. 05

    Clustering agglomératif : 75 clusters → accuracy 0.823.

  6. 06

    ACP + Boruta : 23 composantes (90 % variance). Boruta : réduction 156→135 features, accuracy maintenue à 0.922.

05Difficultés rencontrées

  • DTW très lent : réduction par médiane par classe nécessaire (6 min vs >30 min)
  • Confusion persistante classes 0/1 (battements normaux vs inconnus) sur toutes les méthodes
  • KMeans : clusters vides pour n_clusters > 39

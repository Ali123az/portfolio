ECG arrhythmia classification: supervised and unsupervised learning

MIT-BIH Arrhythmia classification (5 classes, 156 features/signal). KNN, RandomForest, KMeans, agglomerative clustering. SHAP, Boruta, PCA analysis.

01Context

Two-person project at ENSEEIHT: comparison of supervised and unsupervised methods on real biomedical data (MIT-BIH Arrhythmia dataset).

02Technical pipeline

  1. 1MIT-BIH dataset
  2. 2PCA 23 components (90%)
  3. 3GridSearchCV
  4. 4RandomForest 200 est.
  5. 5SHAP + Boruta

03What I did

  1. 01

    DTW (Dynamic Time Warping): per-class median signal computation (6 min vs >30 min brute), baseline 0.575.

  2. 02

    KNN: GridSearch → Manhattan metric, k=1, accuracy 0.924.

  3. 03

    RandomForest: 200 estimators, GridSearch → accuracy 0.925 (best result).

  4. 04

    KMeans: silhouette analysis optimization → 39 clusters → accuracy 0.790.

  5. 05

    Agglomerative clustering: 75 clusters → accuracy 0.823.

  6. 06

    PCA + Boruta: 23 components (90% variance). Boruta: 156→135 feature reduction, accuracy maintained at 0.922.

05Challenges

  • DTW very slow: per-class median reduction required (6 min vs >30 min)
  • Persistent class 0/1 confusion (normal vs unknown beats) across all methods
  • KMeans: empty clusters beyond n_clusters > 39

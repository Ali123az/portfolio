Edge AI: smart sensor on a microcontroller with integrated NPU

NXP Semiconductors · Internship · M1 · May – Sept. 2024

Full Edge AI pipeline: SPI accelerometer acquisition, dataset generation, Conv1D CNN training, INT8 quantization, deployment on NXP Neutron NPU — ×42 speedup on int8 Conv1D operations.

01Context

Project carried out during my internship at NXP Semiconductors, in connection with ENSEEIHT. Goal: demonstrate a complete Edge AI pipeline on a microcontroller with an integrated NPU (FRDM-MCXN947 board), documented well enough to be reused as lab material.

02Technical pipeline

  1. 1FXLS8974 via SPI
  2. 2C state machine
  3. 3CSV dataset (UART)
  4. 4Conv1D CNN (GPU)
  5. 5PTQ INT8
  6. 6Neutron NPU eIQ

03What I did

  1. 01

    Hardware configuration on MCXN947: SPI master (non-blocking LPSPI), GPIO, timer, UART via NXP SDK.

  2. 02

    C state machine (INIT→ACQUIRE→SAVE→SEND) synchronized on FXLS8974 INT1. Two’s complement reading via non-blocking SPI, decimal conversion. Python UART→CSV script with regex parsing.

  3. 03

    Manual dataset collection: gestures (digits 0–9), organized by class for supervised training.

  4. 04

    Conv1D CNN design and training (3 conv layers, BatchNorm, Dropout, AveragePooling, Dense — 13,010 parameters). GPU training with EarlyStopping + ReduceLROnPlateau. Accuracy 99.3%.

  5. 05

    PTQ int8 quantization with representative dataset, float32→int8 conversion, post-quantization evaluation. Memory estimation via tflite-tools (peak: 131,440 bytes).

  6. 06

    NPU deployment: conversion via eIQ Portal (Neutron Converter), mandatory Softmax layer removal (tflite-extractor). C++ MCU integration: .tflite as .rodata, MicroMutableOpResolver, scale/zero-point adjustment.

  7. 07

    Wrote the 37-page technical deployment guide, reused as the reference document.

05Challenges

  • Toolchain compatibility: GNU ARM v12.3 required (v13.2 NPU-incompatible)
  • NPU supports int8 PCQ only: mandatory Softmax removal via tflite-extractor
  • Peak RAM empirically unpredictable (131 kB estimated → 256 kB allocated for safety)
  • MCU debugging: JSON probe errors, serial port conflicts, INT1 accelerometer sync

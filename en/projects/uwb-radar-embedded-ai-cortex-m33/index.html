UWB radar: real-time CNN classification on a Cortex-M33

Vitesco Technologies / Schaeffler France · Apprenticeship · M2 · Sept. 2024 – Oct. 2025

Full embedded pipeline for an automotive Hands-Free Access system: UWB radar acquisition, time-frequency processing via FFT on DSP, real-time CNN inference on ARM Cortex-M33 (128 kB RAM, 768 kB Flash).

01Context

The previous model (1D temporal CNN) had to be retrained per vehicle type. The goal was to design a universal approach based on time-frequency representation, deployable in real time on the NXP Ranger5 MCU without performance trade-offs.

02Technical pipeline

  1. 1UWB CIR Acquisition
  2. 2FFT 32pts + Hanning
  3. 3Time-freq images 20×23×6
  4. 4Compact Conv2D CNN
  5. 5Real-time INT8 Inference

03What I did

  1. 01

    MATLAB simulation of the embedded DSP via NXP DSP Toolbox to replicate Ranger5 behavior and generate ~1100 time-frequency images (CSV) from multi-vehicle CIR recordings. Updated trigger algorithm (IQ segmentation, 384-point window).

  2. 02

    Python preprocessing: per-tap normalization, CIR clipping (6×32→6×20), frequency modulation augmentation, false gesture removal via inter-tap cosine similarity, legacy data adaptation (SNR 6.7→11.2) via tap-by-tap statistical alignment.

  3. 03

    Conv2D CNN design with Optuna automatic optimization (400 trials, multi-criteria objective: loss, TPR, 1-FPR, size, latency). Hard constraints: <25k parameters, <80 kB float, <30 kB post-quantization. AdamW + ReduceLROnPlateau.

  4. 04

    Model optimization: gradual pruning (~49% sparsity/layer), weight clustering (95.62% ratio), QAT 2 phases + PTQ INT8 — 50.94% size reduction (24.33→11.94 kB).

  5. 05

    C embedded FFT pipeline implementation (MATLAB autocoder insufficient): BbCopy, Hanning, FFT 32pts, ComplexToPolar, buffer accumulation. TFLite Micro integration: operator resolver, static tensor arena (~60 kB/128 kB RAM), int8 input quantization.

  6. 06

    Field clinic testing: 3 participants, kick catalog, CAN reading via Arduino + buzzer. End-to-end pipeline validated on Ranger5: 70% detection, 100% false positive immunity.

05Challenges

  • Full manual FFT pipeline reimplementation in C (MATLAB autocoder incomplete on custom DSP functions)
  • 128 kB RAM: 60 kB tensor arena, iterative trial-and-error adjustment to avoid OOM
  • Pruning/clustering without real gains on TFLM Cortex-M33 (no native sparse kernels)
  • Legacy data adaptation (hardware SNR differences) via per-tap and per-vehicle statistical alignment
  • Python/C mismatch: preprocessing not perfectly aligned, causing detection drop in real conditions
